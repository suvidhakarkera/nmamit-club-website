# NMAMIT Club Website

A simple static website showcasing student clubs at NMAM Institute of Technology. This repository contains the HTML, CSS, JavaScript, and media assets used to build the site.

## Features
- Home page with links to individual club pages
- Dedicated pages for events, contact, and club details
- Lightweight, plain-HTML structure suitable for hosting on GitHub Pages or any static web host

## Project structure

- `index.html` — Main landing page
- `homepage.css`, `styles.css` — Global and page styles
- `script.js` — Client-side JavaScript used by the site
- `about.html`, `clubpage.html`, `clubdetails.html`, `events.html`, `contactus.html` — Content pages
- `photos/` — Club logos and image assets
- Other files: `video2.vn`, `Untitled-1.html` (work-in-progress)
